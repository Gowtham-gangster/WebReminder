# WebReminder

A web-based reminder application that helps you stay on top of your tasks and important events.

## Features

- 📝 Create and manage reminders
- ⏰ Set custom reminder times
- 🔔 Get notifications for your reminders
- 💾 Persistent storage of reminders
- 🎨 User-friendly interface
- 📱 Responsive design

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone https://github.com/Gowtham-gangster/WebReminder.git
cd WebReminder
```

2. Install dependencies
```bash
npm install
```

3. Start the application
```bash
npm start
```

The application will be available at `http://localhost:3000`

## Usage

1. Open the application in your web browser
2. Click on "Create Reminder" button
3. Enter your reminder details (title, description, date, time)
4. Click "Save" to create the reminder
5. View your reminders in the dashboard
6. Edit or delete reminders as needed
